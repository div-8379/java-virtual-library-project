# Java Virtual Library System

A console-based Virtual Library Management System developed using Java as an academic project during Semester 4 of my BE Computer Engineering course.

## About the Project

This project was created to apply the Java programming concepts learned during the semester and gain practical experience by building a simple library management system.

## Features

- **View Books:** Display all available books and their sections.
- **Add Books:** Add new books with their IDs, names, authors, and sections.
- **Issue Books:** Issue books from different sections and update the remaining copy count.
- **Popular Book Recommendation:** Recommend a book based on the lowest number of remaining copies.
- **Book Sections:** Organize books into Fiction, Technology, History, and Philosophy.

## Technologies Used

- Java
- Scanner class for user input
- Arrays, classes, objects, and methods
- Conditional statements and loops

## How to Run

1. Install the Java Development Kit (JDK).
2. Save the source code as `VirtualLibrarySystem.java`.
3. Open a terminal in the folder containing the file.
4. Compile the program:

   ```bash
   javac VirtualLibrarySystem.java
   ```

5. Run the program:

   ```bash
   java VirtualLibrarySystem
   ```

Through this project, I practised Java fundamentals, object-oriented programming concepts, array handling, user input, and menu-driven program development.
